# bug3：离目标还很远，机械臂在原地抖

```
[apf_node]: tool 0.341 m, link 0.195 m, self 0.030 m, speed 0.040 m/s, pos_err 0.6101 m, ori_err 0.1492 rad
[apf_node]: tool 0.350 m, link 0.195 m, self 0.031 m, speed 0.040 m/s, pos_err 0.6180 m, ori_err 0.2279 rad
[apf_node]: tool 0.351 m, link 0.195 m, self 0.031 m, speed 0.040 m/s, pos_err 0.6189 m, ori_err 0.2247 rad
[apf_node]: tool 0.350 m, link 0.195 m, self 0.031 m, speed 0.040 m/s, pos_err 0.6185 m, ori_err 0.2218 rad
[apf_node]: tool 0.352 m, link 0.195 m, self 0.031 m, speed 0.040 m/s, pos_err 0.6195 m, ori_err 0.2167 rad
```

约 8 秒里，位置误差从 0.610 m 变成 0.619 m。按日志里的 0.040 m/s 走，这段时间本该靠近大约 0.32 m。

## 日志里每个数是什么

- `speed` 是势场算出来的末端指令快慢，不是末端真的在动多快。它顶在 `v_max = 0.04`。
- `tool` 是末端到球表面的空隙。0.34 m，大于影响距离 `d0 = 0.20`，末端这边的斥力是 0。0.04 m/s 全是往目标拉。
- `link` 是连杆胶囊到球的最近空隙。0.195 m，刚进 0.20 m 的影响区。
- `self` 是不相邻连杆胶囊之间的最近空隙。0.030–0.031 m，贴着自碰撞影响距离 `self_d0 = 0.03`。

## 先排除上次的抖

上次抖是快到目标时，腕关节力矩来回翻。这次位置还差 0.61 m，而且力矩已经按每个关节有多沉来给。这次的参考本身就在来回跳。

## 连杆对球的推力很轻

空隙 `d`、影响距离 `d0`、系数 `k` 时，推力大小是：

```
k * (1/d - 1/d0) / d^2     d < d0 时才有，否则是 0
```

`link = 0.195`，`k_rep = 0.02`，`d0 = 0.20`：

```
0.02 * (1/0.195 - 1/0.20) / 0.195^2 ≈ 0.067
```

这个数再乘关节对那个点的力臂（大约零点几米），关节速度只有百分之几 rad/s。五条日志里 `link` 都是 0.195，没有贴着边界来回穿。它把某根连杆轻轻托在球外面，不是抖的来源。

## 自碰撞这层壳又薄又硬

同一条公式，`k_self = 0.02`，`self_d0 = 0.03`。空隙大于等于 0.03 m 时推力是 0。刚穿进去一点：

| 空隙 | 推力大小 | 力臂按 0.3 m，关节速度 |
| --- | --- | --- |
| 0.031 m | 0 | 0 |
| 0.030 m | 0 | 0 |
| 0.0299 m（往里 0.1 mm） | 2.5 | 0.75 rad/s，已经超过上限 |
| 0.029 m（往里 1 mm） | 27 | 8 rad/s，被削到上限 |

关节速度上限是 `qdot_avoid = 0.5`。能“轻轻推”的那一层不到 0.1 mm。再往里，参加这件事的关节全部顶在 ±0.5 rad/s。

势场每秒算 50 次，但每一步按 `trajectory_horizon = 0.1` s 往前积。顶满的关节一步就是：

```
0.5 rad/s * 0.1 s = 0.05 rad ≈ 2.9°
```

前臂长约 0.48 m，这一步末端大约动 2.4 cm。吸引场同一步只有 `0.04 * 0.1 = 0.4` cm。弹出的一步比靠近目标的一步大约 6 倍。

这 2.4 cm 比那层 0.1 mm 的缓坡大两百多倍。手臂一碰到 3 cm 的壳，下一步就把空隙甩回 3 cm 外面，推力马上变成 0。吸引场还在用全速把手臂折向目标，不相邻的连杆又靠回去。再碰壳，再被弹出。

6 个关节没有多余的空余动作。自碰撞速度是直接加在“去目标”的关节速度上的，所以这一脚会把末端从目标上拽开。位置误差因此停在 0.61 m，姿态误差还会先被带大（0.15 rad 到 0.23 rad）。

日志里 `self` 一直印成 0.030 或 0.031，就是卡在这层壳的两侧。2 秒才印一次，看不见 50 Hz 的来回，只能看见空隙不离开这个边界。

## 结论

抖是自碰撞壳上的来回弹。去目标的动作把不相邻连杆收进 3 cm 以内，壳内不到 0.1 mm 就把关节速度打满，0.1 s 的一步又把它们甩出去。推力消失后再收进来，于是原地抖，位置误差不降。
